# StrikeZone: Zero Hour

An original mobile multiplayer FPS and battle-royale game built with Unity.

## Project

StrikeZone: Zero Hour is an original fast-paced mobile FPS featuring:

- Battle Royale
- Team Deathmatch
- Original specialists
- Custom weapons
- Vehicles
- Dynamic weather
- Mobile controls
- Multiplayer gameplay

## Development

Built with Unity and C#.

## Status

Prototype development.
